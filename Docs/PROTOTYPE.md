# Beastbound Kingdom — Mobile Prototype

## Target
- Platform: Android/iOS
- Orientation: Landscape
- View: Third-person
- Input: left virtual joystick + right attack/interact buttons
- First vertical slice: explore, fight, gain Beast Power, collect resources, return to shelter.

## Unreal setup
Create an Unreal Engine 5 Third Person C++ project named `BeastboundKingdom` and copy/merge the repository `Source` and `Config` files into it. The repository intentionally keeps the gameplay layer engine-friendly rather than pretending that an Unreal `.uproject` can be generated by GitHub alone.

## Mobile controls
Use Unreal's Enhanced Input system:
- Move: left virtual joystick
- Look: right-side touch drag
- Attack: right-side attack button
- Interact: contextual button

## Prototype systems
1. `ABeastPlayerCharacter`: health, Beast Power, axe attack entry point.
2. `ABeastEnemy`: health, simple melee damage, reward on death.
3. `ABeastShelter`: shelter health and upgrade levels.
4. `BeastboundGameMode`: player spawning and prototype rules.

## Next implementation milestone
Add Blueprint assets for the character, beast, shelter, mobile HUD, touch controls, materials, animations, navigation mesh and a small test map. Those binary/editor assets must be authored in Unreal Editor; they cannot be faithfully generated as plain GitHub text files.
